Titanic Exploratory Data Analysis (EDA)

📌 Project Overview
This project is part of the Data Analyst Internship Task 5. The objective is to perform Exploratory Data Analysis (EDA) on the Titanic Dataset to identify patterns, trends, relationships, and insights using statistical methods and data visualization techniques.

🎯 Objective
- Understand the dataset structure and features.
- Analyze passenger demographics and survival patterns.
- Identify relationships between variables.
- Visualize data using charts and plots.
- Generate meaningful insights from the dataset.

🛠️ Tools & Libraries Used
- Python
- Google Colab
- Pandas
- NumPy
- Matplotlib
- Seaborn

📂 Dataset
Titanic Dataset containing passenger information such as:
- Passenger Class
- Age
- Gender
- Fare
- Embarked Port
- Survival Status

📊 Exploratory Data Analysis Performed
Data Understanding
- Dataset overview using `.info()`
- Statistical summary using `.describe()`
- Missing value analysis
- Value counts for categorical variables

Visualizations
- Histograms
- Boxplots
- Countplots
- Scatterplots
- Correlation Heatmap
- Pairplot

Analysis Conducted
- Survival distribution analysis
- Gender-wise survival comparison
- Passenger class impact on survival
- Age distribution analysis
- Fare distribution and outlier detection
- Correlation analysis between numerical features

🔍 Key Findings
- Female passengers had a higher survival rate than male passengers.
- First-class passengers were more likely to survive than passengers in lower classes.
- Most passengers were between 20 and 40 years of age.
- Fare contained several outliers.
- Higher ticket fares were generally associated with better survival chances.
- Passenger class and fare showed noticeable influence on survival outcomes.
